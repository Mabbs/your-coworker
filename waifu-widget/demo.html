独立组件包 · live2d 风格看板娘

给你的网站养一只可以到处拖的「同事」

这是一个普通的博客页面。左下角的 Spine 看板娘悬浮在页面之上——按住她身上任意不透明的地方即可拖到页面任何角落，点击她会有反应，点 👕 可以打开完整的换装间，她还会看向你的鼠标、跟着你的键盘鼠标做动作。她身后的区域照常可以选中文字、点击链接。

🖱️ 随意拖动

像素级透明命中检测：只有真正点到角色身上的像素才会接管拖拽，空白处完全穿透，不会挡住页面交互。

👗 完整换装

头饰、面饰、套装、上衣、下装、腿部、尾巴、道具八个部位，数据来自游戏原版 ItemTable，含稀有度与套装冲突规则。

👁️ 视线跟随

头部与瞳孔跟随页面鼠标平滑转动，睫毛不乱滑，指针离开页面自动回正。

⌨️ 键鼠联动

在页面里打字她就敲键盘、点鼠标她就点鼠标——复刻原游戏 listenInputDevice 桌宠行为。

🖥️ 办公桌场景

一键搬来办公桌（椅子 + 桌体 + 电脑）：与角色同一坐标空间，椅子正好落在她身下，还原游戏原版摆位。

💾 自动记忆

位置、大小、穿搭、办公桌开关全部保存在 localStorage，刷新页面后原样恢复。

📦 自包含包

本目录（runtime / 换装数据 / 模型 / 样式）整体拷走即可部署到任意静态目录或 CDN。

如何嵌到你自己的网站

整个组件零构建，只需要两行代码。把 waifu-widget/ 目录放到网站任意可访问的路径，然后在页面底部加入：

<script src="/path/to/waifu-widget/waifu-widget.js" defer></script>
<script>
  window.addEventListener('DOMContentLoaded', function () {
    WaifuWidget.mount(); // 可传 { width: 300, x: 40, y: 400, base: 'https://cdn.example.com/waifu-widget/' }
  });
</script>

或者使用一行式自动挂载：

<script src="/path/to/waifu-widget/waifu-widget.js" data-ycw-auto defer></script>

试试这些

拖住她移动 → 松手；单击她的身体 → 触碰反应；移动鼠标 → 她的头和眼睛跟着看；在页面上打字 → 她敲键盘；点页面 → 她点鼠标；等 10~20 秒 → 随机小动作；👕 → 换装间；🎲 → 随机穿搭；＋/－ → 缩放；✕ → 收起（右下角可召回）。

注意：由于浏览器对 fetch 的限制，请通过 HTTP 服务（如 python -m http.server 或 npx serve）访问本页，直接双击打开 HTML 文件无法加载模型资源。

关于这个角色

看板娘模型来自 Mabbs/your-coworker 项目解包的 Spine 4.3 骨骼动画（PoseA · 坐姿办公同事，241 个皮肤），渲染基于 spine-webgl，换装规则来自游戏 ItemTable。
